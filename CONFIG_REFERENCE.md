# Configuration Reference

## Safety and Mode Controls

- `AUTONOMOUS_REQUIRE_OPERATOR_LIVE_CONFIRMATION`:
  - `1` enables manual live gate enforcement (default).
- `AUTONOMOUS_LIVE_GO`:
  - must be `1` for live startup.
- `AUTONOMOUS_LIVE_OPERATOR_CONFIRMATION_FILE`:
  - required confirmation artifact path for live startup.
- `AUTONOMOUS_GUARDS_MODE`:
  - `strict` or `fatal_only`.

## Distributed Runtime

- `AUTONOMOUS_DISTRIBUTED_ENABLED`
- `AUTONOMOUS_NODE_ROLE` (`live` or `compute`)
- `AUTONOMOUS_COMPUTE_BRIDGE` (`auto|redis|local|disabled`)
- `AUTONOMOUS_REDIS_URL`
- `AUTONOMOUS_STREAM_PREFIX`
- `AUTONOMOUS_STREAM_PAYLOAD_VERSION`
- `AUTONOMOUS_CONSUMER_GROUP_LIVE_NODE`
- `AUTONOMOUS_CONSUMER_GROUP_COMPUTE_NODE`
